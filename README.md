### 2. Turmeric Shield

**Smart India Hackathon 2026 — SIH26131 — Team Code4Cause**

Turmeric Shield is an explainable early-warning and decision-support prototype for **turmeric rhizome-rot risk**.

The system combines field conditions, weather context, crop context, and local case patterns to prioritize fields for inspection and recommend appropriate next steps.

### Core Workflow

**Monitor → Assess → Prioritize → Act → Verify → Learn**

### Key Features

- Structured field and environmental inputs
- Weather-context integration
- Crop-context analysis
- Local-history inputs
- Explainable risk assessment
- HIGH / MODERATE / LOW / UNCERTAIN priorities
- Recommended action and next step
- Python/FastAPI backend
- Streamlit web interface

**Achievement:**  
Cleared the **IIPS DAVV College Internal Round of Smart India Hackathon 2026**.

> This is a prototype decision-support system, not a confirmed disease-diagnosis system.

**Technologies:**  
`Python` `FastAPI` `Streamlit` `GitHub`
